# 0004. Data access: Drizzle

- **Status:** Accepted
- **Date:** 2026-10-21
- **Task:** GW-002

## Context

Owner is new to backend; SQL knowledge is an interview topic. Rollups need aggregate queries.

## Options

| Option | Pros | Cons |
|---|---|---|
| Drizzle | Reads like SQL; light; TS-first migrations | Smaller ecosystem than Prisma |
| Prisma | Polished DX | Hides SQL; heavier runtime |
| Kysely / raw SQL | Full control | More manual work |

## Decision

Drizzle.

## Consequences

Migrations live in `packages/db` and run in CI against a real Postgres.
